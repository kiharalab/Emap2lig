# Emap2lig Agent Skills

This directory contains agent skills for the [Emap2lig](https://github.com/kiharalab/Emap2lig)
project, following the [Agent Skills specification](https://agentskills.io/specification).

## Using with `npx skills`

```bash
npx skills add kiharalab/Emap2lig --skill emap2lig
```

## Skills

- **`emap2lig/`** — Guides agents through using the Emap2lig CLI and web GUI
  for ligand structure modeling from cryo-EM density maps.
